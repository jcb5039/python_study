# 5장: 입력 받기

> **이 장의 목표:** 키보드나 파일로 값을 입력받아서, 숫자로 바꿔 계산하고 출력할 수 있다.

지금까지는 값을 코드 안에 직접 적었어요. 하지만 코딩테스트 문제는 **"입력이 이렇게 주어지면, 이렇게 출력하라"**는 모양이에요. 그래서 입력 받는 법을 꼭 알아야 해요.

```
[입력]        [내 프로그램]        [출력]
3 5     →     더해서 출력     →     8
```

---

## 1. `input()`: 한 줄 입력받기

`input()`은 사용자가 **한 줄을 쳐서 엔터를 누를 때까지 기다렸다가**, 친 내용을 돌려줘요.

```python
name = input()
print(f'안녕, {name}!')
```

실행하면 아무것도 안 나오고 멈춘 것처럼 보여요. **입력을 기다리는 중**이에요. 터미널에 이름을 치고 엔터를 누르세요.

```
$ python3 hello_input.py
파이썬            ← 내가 친 것
안녕, 파이썬!      ← 프로그램이 출력한 것
```

### 안내 문구 넣기

괄호 안에 글자를 넣으면 입력받기 전에 안내 문구를 보여 줘요.

```python
name = input('이름을 입력하세요: ')
```

```
이름을 입력하세요: 파이썬
```

> ⚠️ **코딩테스트에서는 안내 문구를 절대 넣지 마세요!** 안내 문구도 출력으로 취급돼서, 정답 출력과 달라지면 틀린 답이 돼요. 그냥 `input()`만 써요.

---

## 2. 입력은 항상 문자열이에요

이게 이 장에서 **가장 중요한 내용**이에요.

```python
a = input()
print(type(a))
print(a + a)
```

```
15                 ← 입력
<class 'str'>
1515
```

`15`를 쳤는데 `str`(문자열)이에요! `input()`은 무엇을 치든 **항상 문자열로** 돌려줘요. 그래서 `a + a`가 `30`이 아니라 `'1515'`가 됐어요.

### 숫자로 쓰려면 바로 바꿔요

2장에서 배운 형변환을 써요.

```python
a = int(input())
print(a + a)
```

```
15     ← 입력
30
```

`int(input())`은 안쪽부터 실행돼요.

1. `input()`: 한 줄을 읽어서 `'15'`(문자열)를 돌려줌
2. `int('15')`: 정수 `15`로 바꿈
3. `a`에 `15`를 넣음

실수가 필요하면 `float(input())`을 써요.

---

## 3. 한 줄에 여러 값 입력받기

코딩테스트에는 이런 입력이 정말 많아요.

```
3 5
```

한 줄에 숫자 두 개가 띄어쓰기로 나뉘어 있어요. 4장에서 배운 `split()`으로 나눠요.

```python
a, b = input().split()
print(a, b)
```

```
3 5      ← 입력
3 5
```

하지만 `a`와 `b`는 아직 **문자열** `'3'`, `'5'`예요. 하나씩 바꿔도 되지만,

```python
a, b = input().split()
a = int(a)
b = int(b)
print(a + b)
```

### `map`으로 한 번에 바꾸기

코딩테스트에서는 이렇게 한 줄로 써요. **이 줄은 외워 두세요.**

```python
a, b = map(int, input().split())
print(a + b)
```

```
3 5      ← 입력
8
```

안쪽부터 하나씩 볼게요.

| 단계 | 코드 | 결과 |
| --- | --- | --- |
| 1 | `input()` | `'3 5'` |
| 2 | `input().split()` | `['3', '5']` |
| 3 | `map(int, ...)` | 조각 **각각에** `int`를 적용 → `3`, `5` |
| 4 | `a, b = ...` | `a`에 `3`, `b`에 `5` |

`map(int, 조각들)`은 **"조각들 하나하나에 `int`를 해 줘"**라는 뜻이에요. 공장 컨베이어 벨트처럼 조각이 하나씩 지나가면서 `int` 기계를 통과해 숫자가 되는 거예요.

숫자가 세 개면 변수도 세 개로 받아요.

```python
a, b, c = map(int, input().split())
```

### 개수가 안 맞으면 에러

```python
a, b = map(int, input().split())
```

```
1 2 3     ← 입력 (3개)
ValueError: too many values to unpack (expected 2)
```

"값이 너무 많아서 풀 수가 없어요. 2개를 기대했어요"라는 뜻이에요. 입력 개수와 변수 개수가 같아야 해요. 개수를 모를 때 받는 방법은 8장(리스트)에서 배워요.

## 4. 여러 줄 입력받기

`input()` 한 번이 **한 줄**이에요. 두 줄이면 두 번 불러요.

```python
name = input()
age = int(input())
print(f'{name}님은 {age}살이에요')
```

```
민지        ← 입력 1번째 줄
25          ← 입력 2번째 줄
민지님은 25살이에요
```

> 💡 입력이 몇 줄이고 각 줄에 무엇이 있는지는 문제의 **[입력]** 설명에 항상 적혀 있어요. 그걸 보고 `input()`을 몇 번, 어떻게 부를지 정해요.

### 입력보다 `input()`을 많이 부르면

입력은 2줄인데 `input()`을 3번 부르면, 세 번째에서 읽을 줄이 없어서 에러가 나요.

```
EOFError: EOF when reading a line
```

`EOF`는 **E**nd **O**f **F**ile, "입력이 끝났어요"라는 뜻이에요.

## 5. 매번 입력을 치기 귀찮을 때: 파일로 넣기

테스트할 때마다 같은 입력을 치는 건 귀찮아요. 입력을 **파일에 적어 두고** 넣을 수 있어요.

1. `input.txt` 파일을 만들고 입력을 적어요.

```
3 5
```

2. 실행할 때 `<` 뒤에 파일 이름을 써요.

```bash
python3 my_sum.py < input.txt
```

```
8
```

`<`는 "키보드 대신 이 파일 내용을 입력으로 넣어 줘"라는 뜻이에요.

### judge.py가 하는 일

이 장의 문제를 채점하는 `judge.py`도 똑같은 일을 해요. `cases/` 폴더에 준비된 입력을 내 프로그램에 넣고, 출력이 정답과 같은지 비교해요.

```bash
python3 judge.py exercises/ch05/ex02_sum.py
```

```
✅ 1번
❌ 2번: 출력이 달라요.
  [넣어 준 입력]
    100 -30
  [정답 출력]
    70
  [내 출력]
    100-30
```

틀리면 **어떤 입력에서 어떻게 달랐는지** 보여 주니까 그걸 보고 고치면 돼요. 실제 코딩테스트 사이트도 이렇게 여러 입력으로 채점해요. 하나만 맞으면 안 되고 **전부** 맞아야 해요.

## 6. 출력 모양 맞추기

코딩테스트는 출력이 **글자 하나까지** 같아야 해요. 자주 쓰는 출력 방법을 정리할게요.

```python
a, b = 3, 5
print(a + b)              # 8
print(a, b)               # 3 5        (쉼표: 사이에 띄어쓰기)
print(f'{a}+{b}={a+b}')   # 3+5=8      (f-string: 원하는 모양 그대로)
print(a)                  # 3          (print를 따로 쓰면 줄이 바뀜)
print(b)                  # 5
```

## 7. 자주 하는 실수

| 실수 | 결과 | 고친 모습 |
| --- | --- | --- |
| `a = input()` 후 바로 `a + 1` | `TypeError` | `a = int(input())` |
| `input('숫자 입력: ')` | 코테에서 오답 | `input()` |
| `int(input().split())` | `TypeError` | `map(int, input().split())` |
| `a, b = map(int, input())` (split 빠짐) | 글자 하나하나를 나눔 → 에러 | `input().split()` |
| 한 줄에 두 값인데 `input()`을 두 번 | `EOFError` 또는 `ValueError` | 한 줄은 `input()` 한 번 |
| 실행했더니 멈춰 있음 | 입력을 기다리는 중 | 값을 치고 엔터. 끝내려면 `Ctrl + C` |
