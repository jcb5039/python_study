# 1장: 첫 프로그램

> **이 장의 목표:** 파이썬 파일을 만들고, 실행하고, 에러가 나면 메시지를 읽고 고칠 수 있다.

---

## 1. 프로그램이 뭐예요?

**프로그램**은 컴퓨터에게 시킬 일을 순서대로 적어 둔 **명령서**예요.
요리 레시피와 비슷해요. 레시피에 "물을 끓인다 → 면을 넣는다 → 3분 기다린다"라고 적혀 있으면 위에서부터 차례대로 하잖아요. 컴퓨터도 명령서를 **위에서 아래로 한 줄씩** 읽으면서 실행해요.

**파이썬(Python)**은 이 명령서를 쓰는 **언어** 중 하나예요. 사람 말과 비슷하게 읽혀서 처음 배우기 좋고, 코딩테스트에서도 가장 많이 쓰는 언어 중 하나예요.

| 용어 | 뜻 |
| --- | --- |
| 코드 | 파이썬으로 쓴 명령 한 줄 한 줄 |
| 파이썬 파일 | 코드를 저장한 파일. 이름이 `.py`로 끝나요 (예: `hello.py`) |
| 실행 | 컴퓨터에게 "이 파일에 적힌 명령을 해 줘"라고 시키는 것 |

---

## 2. 터미널이 뭐예요?

평소에는 마우스로 아이콘을 눌러서 프로그램을 켜죠. **터미널**은 마우스 대신 **글자로 명령을 쳐서** 컴퓨터를 다루는 창이에요.

VS Code에서 **터미널 → 새 터미널**을 누르면 화면 아래에 이런 줄이 보여요.

```
chanbeom@MacBookPro python-study %
```

- `python-study`: 지금 내가 **어느 폴더에 있는지** 알려 줘요.
- `%`: "명령을 기다리고 있어요"라는 표시예요. 이 뒤에 명령을 쳐요.

### 터미널에 처음 쳐 볼 명령

```bash
python3 --version
```

글자를 치고 **엔터**를 누르면 이렇게 나와요. (숫자는 조금 다를 수 있어요.)

```
Python 3.15.2
```

파이썬이 컴퓨터에 설치되어 있다는 뜻이에요.

> ⚠️ 맥에서는 `python`이 아니라 **`python3`**라고 쳐야 해요.

### 폴더 이동하기

터미널이 `python-study` 폴더에 있지 않으면 이렇게 이동해요.

```bash
cd ~/src/python-study
```

`cd`는 **c**hange **d**irectory(폴더 바꾸기)의 줄임말이에요.

## 3. 첫 파이썬 파일 만들기

1. VS Code 왼쪽 탐색기에서 `python-study` 폴더에 마우스를 올리고 **새 파일** 아이콘을 눌러요.
2. 이름을 `hello.py`로 지어요.
3. 파일에 이 한 줄을 **직접 쳐요**.

```python

```

4. `Cmd + S`로 저장해요.
5. 터미널에서 실행해요.


```
안녕, 파이썬!
```

> 💡 VS Code 오른쪽 위의 ▶️ 버튼을 눌러도 실행돼요. 하지만 이 강의에서는 터미널에 직접 치는 방법을 써요. 코딩테스트와 실무에서 계속 쓰는 방법이라서 지금 익혀 두면 좋아요.

## 4. `print`: 화면에 글자 보여 주기

`print`는 괄호 안에 넣은 것을 **화면(터미널)에 보여 주는** 명령이에요.

```python
print('안녕하세요')
```

```
안녕하세요
```

### 글자는 따옴표로 감싸요

글자를 쓸 때는 **따옴표**로 감싸야 해요. 따옴표는 "여기부터 여기까지가 글자예요"라는 표시예요.

```python
print('작은따옴표도 되고')
print("큰따옴표도 돼요")
```

```
작은따옴표도 되고
큰따옴표도 돼요
```

둘 다 똑같아요. 이 강의에서는 작은따옴표 `'`를 주로 써요. 단, **여는 따옴표와 닫는 따옴표의 종류가 같아야** 해요. `'안녕"`처럼 섞으면 에러가 나요.

### 숫자는 따옴표 없이 써요

```python
print(7)
print(3 + 4)
print('3 + 4')
```

```
7
7
3 + 4
```

여기가 아주 중요해요.

- `print(3 + 4)`: 따옴표가 **없으니까** 파이썬이 **계산**해서 `7`을 보여 줘요.
- `print('3 + 4')`: 따옴표가 **있으니까** 그냥 **글자**로 보고 그대로 보여 줘요.

### 여러 줄 출력하기

`print`를 여러 번 쓰면 한 줄에 하나씩 나와요. 위에서 아래 순서대로 실행돼요.

```python
print('하나')
print('둘')
print('셋')
```

```
하나
둘
셋
```

### 한 번에 여러 개 출력하기

쉼표 `,`로 나누면 여러 개를 **한 줄에, 띄어쓰기 하나를 사이에 두고** 보여 줘요.

```python
print('사과', 3, '개')
```

```
사과 3 개
```

### 빈 줄 출력하기

괄호 안을 비우면 빈 줄이 하나 나와요.

```python
print('위')
print()
print('아래')
```

```
위

아래
```

### ✍️ 직접 해보기

`hello.py`를 이렇게 바꾸고 실행해 보세요. 결과를 먼저 예측해 본 다음 실행하세요.

```python
print('계산 결과:', 10 * 3)
print(10 - 3)
print('10 - 3')
```

> `*`는 곱하기예요. 키보드에 `×`가 없어서 `*`를 써요.

## 5. 주석: 컴퓨터는 무시하는 메모

`#` 뒤에 쓴 글은 **주석**이에요. 컴퓨터는 주석을 읽지 않고 건너뛰어요. 사람이 읽으라고 남기는 메모예요.

```python
# 이 줄은 실행되지 않아요
print('이 줄은 실행돼요')  # 줄 뒤에도 메모를 달 수 있어요
```

```
이 줄은 실행돼요
```

주석은 이럴 때 써요.

- 코드가 무슨 일을 하는지 설명할 때
- 어떤 줄을 잠깐 실행하지 않게 막아 두고 싶을 때

> 💡 VS Code에서 줄을 선택하고 `Cmd + /`를 누르면 주석으로 바꾸거나 다시 되돌릴 수 있어요.

## 6. 에러: 무서워하지 말고 읽기

코드를 잘못 쓰면 파이썬이 **에러 메시지**를 보여 줘요. 에러는 실패가 아니라 **"여기가 이상해요"라고 알려 주는 안내문**이에요. 개발자는 하루에도 에러를 수십 번 봐요.

### 에러 읽는 순서

1. **맨 아래 줄**부터 읽어요. 에러의 **종류와 이유**가 적혀 있어요.
2. 그 위의 **`line 숫자`**를 봐요. **몇 번째 줄**이 문제인지 알려 줘요.
3. `^^^` 표시는 그 줄의 **어느 부분**이 문제인지 가리켜요.

### 예시 1: 오타 (NameError)

```python
print('안녕')
pritn('파이썬')
```

```
안녕
Traceback (most recent call last):
  File ".../hello.py", line 2, in <module>
    pritn('파이썬')
    ^^^^^
NameError: name 'pritn' is not defined. Did you mean: 'print'?
```

- 맨 아래 줄: `pritn`이라는 이름을 모르겠대요. 친절하게 **"`print` 말하는 거예요?"**라고 물어봐 줘요.
- `line 2`: 2번째 줄이 문제예요.
- 1번째 줄 `안녕`은 정상적으로 출력됐어요. 파이썬은 위에서부터 실행하다가 **에러가 난 줄에서 멈춰요.**

### 예시 2: 따옴표를 안 닫음 (SyntaxError)

```python
print('안녕)
```

```
  File ".../hello.py", line 1
    print('안녕)
          ^
SyntaxError: unterminated string literal (detected at line 1)
```

- `SyntaxError`: **문법**이 틀렸다는 뜻이에요. 한국어로 치면 맞춤법이 틀린 거예요.
- `unterminated string`: 글자(string)가 **끝나지 않았다**는 뜻이에요. 닫는 따옴표가 없어요.

### 예시 3: 글자에 따옴표를 빼먹음 (NameError)

```python
print(안녕)
```

```
NameError: name '안녕' is not defined
```

따옴표가 없으니 파이썬은 `안녕`을 글자가 아니라 **무언가의 이름**으로 생각해요. 그런데 그런 이름은 없으니까 에러가 나요.

### 예시 4: 줄 앞에 띄어쓰기를 넣음 (IndentationError)

```python
print('a')
    print('b')
```

```
  File ".../hello.py", line 2
    print('b')
IndentationError: unexpected indent
```

파이썬은 **줄 맨 앞의 띄어쓰기(들여쓰기)**를 아주 중요하게 여겨요. 아무 이유 없이 줄 앞에 칸을 띄우면 에러가 나요. 들여쓰기를 언제 쓰는지는 6장에서 배워요. 지금은 **모든 줄을 맨 앞에서 시작한다**고만 기억하세요.

### 에러 종류 정리

| 에러 | 뜻 | 자주 생기는 이유 |
| --- | --- | --- |
| `SyntaxError` | 문법이 틀렸어요 | 따옴표나 괄호를 안 닫음 |
| `NameError` | 그런 이름이 없어요 | 오타, 글자에 따옴표를 빼먹음 |
| `IndentationError` | 들여쓰기가 이상해요 | 줄 앞에 쓸데없는 띄어쓰기 |

## 7. 자주 하는 실수

| 실수 | 고친 모습 |
| --- | --- |
| `Print('안녕')` (대문자 P) | `print('안녕')`: 파이썬은 대문자와 소문자를 다른 글자로 봐요 |
| `print('안녕'` (괄호 안 닫음) | `print('안녕')` |
| `print('안녕")` (따옴표 종류 섞음) | `print('안녕')` |
| `print ('안녕')` (print 뒤에 띄어쓰기) | 동작은 하지만 보통 붙여 써요: `print('안녕')` |
| 저장 안 하고 실행 | `Cmd + S`로 저장한 다음 실행해요. 파일 탭 이름 옆에 ● 표시가 있으면 저장이 안 된 거예요 |
| `python hello.py` | 맥에서는 `python3 hello.py` |
