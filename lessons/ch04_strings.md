# 4장: 문자열

> **이 장의 목표:** 문자열에서 원하는 글자를 꺼내고, 자르고, 바꾸고, 변수를 넣어 예쁘게 만들 수 있다.

**문자열(str)**은 글자들이 **한 줄로 늘어선 것**이에요. 코딩테스트에는 "문자열을 뒤집어라", "특정 글자가 몇 개냐" 같은 문제가 정말 많이 나와요.

---

## 1. 인덱스: 글자마다 붙은 번호

문자열의 글자마다 **번호(인덱스)**가 붙어 있어요. 번호는 **0부터** 시작해요.

```
글자:     p   y   t   h   o   n
번호:     0   1   2   3   4   5
뒤에서:  -6  -5  -4  -3  -2  -1
```

`문자열[번호]`로 그 자리의 글자를 꺼내요.

```python
word = 'python'
print(word[0])     # 첫 번째 글자
print(word[5])     # 여섯 번째 글자
print(word[-1])    # 맨 뒤 글자
print(word[-2])    # 뒤에서 두 번째
```

```
p
n
n
o
```

### 왜 0부터 시작해요?

번호를 **"맨 앞에서 몇 칸 떨어져 있는지"**로 생각하면 쉬워요. 첫 글자는 맨 앞에서 0칸, 두 번째 글자는 1칸 떨어져 있어요. 거의 모든 프로그래밍 언어가 이렇게 세요.

### 음수 번호는 뒤에서부터

`-1`은 맨 뒤, `-2`는 뒤에서 두 번째예요. 문자열 길이를 몰라도 마지막 글자를 바로 꺼낼 수 있어서 편해요.

### `len()`: 길이 구하기

```python
word = 'python'
print(len(word))
print(len(''))
```

```
6
0
```

길이가 6이면 번호는 0부터 **5까지**예요. 마지막 번호는 항상 `len(word) - 1`이에요.

### 없는 번호를 쓰면 에러

```python
word = 'python'
print(word[10])
```

```
IndexError: string index out of range
```

`IndexError`는 **번호가 범위를 벗어났다**는 에러예요. 코딩테스트에서 정말 자주 보게 될 거예요.

---

## 2. 슬라이싱: 잘라서 꺼내기

`문자열[시작:끝]`으로 **일부분을 잘라** 꺼낼 수 있어요.

> ⚠️ **시작 번호는 포함, 끝 번호는 포함하지 않아요.**

```python
word = 'python'
print(word[0:2])    # 0, 1번 (2번은 안 들어감)
print(word[2:5])    # 2, 3, 4번
```

```
py
tho
```

"끝 번호는 안 들어간다"가 헷갈리면 이렇게 생각하세요. `word[2:5]`는 **2번부터 시작해서 5 - 2 = 3글자**를 가져와요.

### 시작이나 끝을 비우면

```python
word = 'python'
print(word[:3])     # 처음부터 3글자
print(word[3:])     # 3번부터 끝까지
print(word[:])      # 전체
```

```
pyt
hon
python
```

### 건너뛰며 자르기: `[시작:끝:간격]`

세 번째 숫자는 **몇 칸씩 건너뛸지**예요.

```python
word = 'python'
print(word[::2])     # 처음부터 끝까지 2칸씩
print(word[::-1])    # 뒤에서부터 거꾸로
```

```
pto
nohtyp
```

`[::-1]`은 **문자열 뒤집기**예요. 코딩테스트에서 자주 쓰니까 외워 두세요.

### 문자열은 바꿀 수 없어요

```python
word = 'python'
word[0] = 'P'
```

```
TypeError: 'str' object does not support item assignment
```

문자열의 글자 하나만 쏙 바꿀 수는 없어요. 바꾸고 싶으면 **새 문자열을 만들어서** 다시 넣어요.

```python
word = 'python'
word = 'P' + word[1:]
print(word)
```

```
Python
```

## 3. f-string: 문자열에 변수 넣기

지금까지는 글자와 변수를 합칠 때 쉼표나 `+`를 썼어요.

```python
name = '찬범'
km = 5.24
print(name + '님이 ' + str(km) + 'km 달렸어요')
```

불편하죠? **f-string**을 쓰면 훨씬 쉬워요. 따옴표 앞에 `f`를 붙이고, 넣고 싶은 변수를 **중괄호 `{ }`**로 감싸요.

```python
name = '찬범'
km = 5.24
print(f'{name}님이 {km}km 달렸어요')
```

```
찬범님이 5.24km 달렸어요
```

`str()`로 바꿀 필요도 없어요. f-string이 알아서 글자로 바꿔 줘요.

### 중괄호 안에서 계산도 돼요

```python
price = 3000
print(f'3개는 {price * 3}원이에요')
```

```
3개는 9000원이에요
```

### 소수점 자릿수 정하기: `{값:.2f}`

중괄호 안에서 값 뒤에 `:.2f`를 붙이면 **소수점 2자리까지 반올림해서** 보여 줘요.

```python
pi = 3.14159
print(f'{pi:.2f}')
print(f'{5:.2f}')
print(f'{2 / 3:.1f}')
```

```
3.14
5.00
0.7
```

| 쓰는 법 | 뜻 |
| --- | --- |
| `:.2f` | 소수점 아래 **2자리** |
| `:.1f` | 소수점 아래 **1자리** |
| `:.0f` | 소수점 없이 (반올림) |

자리가 모자라면 `5.00`처럼 0을 채워 줘요. 코딩테스트에서 "소수점 둘째 자리까지 출력하라"는 문제가 나오면 이걸 써요.

> 💡 `f`를 빼먹으면 `'{name}님'`이 글자 그대로 출력돼요. 결과에 중괄호가 보이면 `f`를 확인하세요.

## 4. 문자열 기능 (메서드)

문자열 뒤에 **점(`.`)**을 찍고 기능 이름을 쓰면, 그 문자열에 여러 가지 일을 시킬 수 있어요. 이렇게 값에 딸린 기능을 **메서드**라고 불러요.

> `문자열.기능()` → "이 문자열의 ○○ 기능을 실행해"

### 대소문자 바꾸기

```python
s = 'Hello Python'
print(s.upper())    # 전부 대문자로
print(s.lower())    # 전부 소문자로
```

```
HELLO PYTHON
hello python
```

### 양쪽 공백 지우기: `strip()`

```python
s = '   hello   '
print('[' + s.strip() + ']')
```

```
[hello]
```

양 끝의 띄어쓰기(와 줄바꿈)를 지워요. 가운데 띄어쓰기는 그대로예요.

### 바꾸기: `replace(찾을 것, 바꿀 것)`

```python
print('banana'.replace('a', 'o'))
```

```
bonono
```

### 개수 세기와 찾기

```python
s = 'banana'
print(s.count('a'))    # 'a'가 몇 개?
print(s.find('n'))     # 'n'이 처음 나오는 번호
print(s.find('z'))     # 없으면 -1
```

```
3
2
-1
```

### 들어 있는지 확인: `in`

```python
print('py' in 'python')
print('java' in 'python')
```

```
True
False
```

### 숫자로만 되어 있는지: `isdigit()`

```python
print('123'.isdigit())
print('12a'.isdigit())
```

```
True
False
```

### ⚠️ 메서드도 원래 문자열을 바꾸지 않아요

```python
s = 'hello'
s.upper()
print(s)          # 그대로 hello!

s = s.upper()     # 결과를 다시 담아야 바뀌어요
print(s)
```

```
hello
HELLO
```

문자열은 바꿀 수 없다고 했죠? 그래서 `upper()`는 **대문자로 바뀐 새 문자열을 만들어 줄 뿐**이에요. 결과를 쓰려면 변수에 담아야 해요.

## 5. 나누기와 합치기: `split()`과 `join()`

이 두 개는 5장(입력 받기)부터 **매일** 쓰게 될 거예요.

### `split()`: 잘라서 나누기

```python
date = '2026-11-04'
parts = date.split('-')
print(parts)
```

```
['2026', '11', '04']
```

`'-'`를 기준으로 잘라서 여러 조각으로 만들었어요. 결과의 대괄호 `[ ]`는 **리스트**라는 거예요. 여러 값을 순서대로 담은 묶음인데, 8장에서 자세히 배워요. 지금은 이것만 알면 돼요.

```python
print(parts[0])    # 문자열처럼 번호로 꺼낼 수 있어요
print(parts[1])
```

```
2026
11
```

**괄호를 비우면 띄어쓰기를 기준으로** 잘라요. 띄어쓰기가 여러 칸이어도 알아서 처리해요.

```python
print('사과 바나나   딸기'.split())
```

```
['사과', '바나나', '딸기']
```

### 나눈 조각을 바로 변수에 담기

조각 개수를 알면, 2장에서 배운 "한 줄에 여러 변수" 방법으로 한 번에 담을 수 있어요.

```python
year, month, day = '2026-11-04'.split('-')
print(year)
print(month)
```

```
2026
11
```

> ⚠️ 나눈 조각도 전부 **문자열**이에요. 계산하려면 `int(year)`처럼 바꿔야 해요.

### `join()`: 조각을 합치기

`split`의 반대예요. **사이에 넣을 글자**를 앞에 쓰고, 합칠 조각들을 괄호에 넣어요.

```python
parts = ['2026', '11', '04']
print('/'.join(parts))
print(''.join(parts))
```

```
2026/11/04
20261104
```

## 6. 자주 하는 실수

| 실수 | 결과 | 고친 모습 |
| --- | --- | --- |
| 첫 글자를 `s[1]`로 꺼냄 | 두 번째 글자가 나옴 | 첫 글자는 `s[0]` |
| 마지막 글자를 `s[len(s)]`로 꺼냄 | `IndexError` | `s[-1]` 또는 `s[len(s) - 1]` |
| `s[1:3]`이 3번 글자까지 포함한다고 생각 | 1, 2번만 나옴 | 끝 번호는 포함하지 않아요 |
| `s.upper()`만 쓰고 끝냄 | `s`는 그대로 | `s = s.upper()` |
| f-string에서 `f`를 빼먹음 | `{name}`이 글자 그대로 나옴 | `f'{name}'` |
| `split()` 결과로 바로 계산 | 글자끼리 이어 붙여짐 | `int()`로 바꾸고 계산 |
