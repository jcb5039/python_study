## 1. 코딩테스트 문제의 두 가지 형식

한국 코딩테스트 사이트는 크게 두 가지 형식이에요.

### (1) 입출력형: 백준(acmicpc.net) 같은 곳

**입력을 직접 읽고, 답을 `print`로 출력**해요. 5~8장 문제가 이 모양이었어요.

```
[입력]
첫째 줄에 정수 N이 주어진다.
둘째 줄에 N개의 정수가 주어진다.

[출력]
N개 정수의 합을 출력한다.
```

```python
n = int(input())
nums = list(map(int, input().split()))
print(sum(nums))
```

### (2) 함수형: 프로그래머스(programmers.co.kr) 같은 곳

**`solution` 함수가 미리 주어지고, 답을 `return`**해요. 입력을 직접 읽지 않아요. 9~11장 문제가 이 모양이었어요.

```
[문제]
정수 배열 numbers가 매개변수로 주어질 때, 원소의 합을 return 하도록 solution 함수를 완성해 주세요.

[입출력 예]
numbers           result
[1, 2, 3]         6
```

```python
def solution(numbers):
    return sum(numbers)
```

> 💡 문제에서 "배열"이라고 하면 파이썬의 **리스트**예요. 다른 언어에서는 배열이라고 부르거든요.

| | 입출력형 | 함수형 |
| --- | --- | --- |
| 값을 받는 법 | `input()`으로 직접 읽기 | 매개변수로 받음 |
| 답을 내는 법 | `print()` | `return` |
| 흔한 실수 | 출력 모양이 다름 (띄어쓰기, 줄바꿈) | `print`로 답을 냄, `return` 빠뜨림 |

**두 형식을 섞으면 안 돼요.** 함수형 문제에서 `input()`을 쓰거나, 입출력형 문제에서 `return`만 하면 틀려요.

## 2. 문제 읽는 순서

문제를 보자마자 코드를 치지 마세요. 이 순서를 지키면 틀리는 일이 확 줄어요.

1. **입력과 출력을 먼저 봐요.** 무엇이 들어오고 무엇을 내야 하는지.
2. **예제를 손으로 풀어 봐요.** 종이에 예제 입력을 놓고, 사람이라면 어떻게 답을 구할지 따라가 봐요.
3. **제한 조건을 봐요.** `1 <= N <= 100000` 같은 숫자. 얼마나 빨라야 하는지 알려 줘요. (아래 4번에서 설명)
4. **풀 방법을 한국어로 적어 봐요.** "합을 구한다 → 평균을 낸다 → 평균보다 큰 개수를 센다"처럼.
5. **코드로 옮겨요.** 4번의 한 줄 한 줄이 코드 몇 줄이 돼요.
6. **예제로 확인해요.** 예제 출력과 **글자 하나까지** 같은지.
7. **경계값을 넣어 봐요.** N이 1일 때, 0일 때, 가장 클 때, 모두 같은 값일 때, 음수일 때.

### 예시로 따라 해 보기

> **[문제]** 학생 N명의 점수가 주어진다. 가장 높은 점수와 가장 낮은 점수를 뺀 나머지의 평균을 소수점 첫째 자리까지 출력하라. (3 <= N <= 100)
>
> **[입력 예]**
> ```
> 5
> 80 70 90 60 100
> ```
> **[출력 예]**
> ```
> 80.0
> ```

1. 입력: 첫 줄 N, 둘째 줄 점수 N개 / 출력: 평균 (소수점 첫째 자리)
2. 손으로: 가장 높은 100, 가장 낮은 60을 빼면 80, 70, 90 → 합 240 → 3으로 나누면 80.0
3. 제한: N은 최대 100. 아주 작아요. 무슨 방법이든 괜찮아요.
4. 방법: 점수 합에서 최댓값과 최솟값을 빼고, (N - 2)로 나눈다
5. 코드:

```python
n = int(input())
scores = list(map(int, input().split()))
total = sum(scores) - max(scores) - min(scores)
print(f'{total / (n - 2):.1f}')
```

6. 예제: `80.0` ✅
7. 경계값: 모두 같은 점수 `3 / 50 50 50` → 50.0 ✅ / 최고점이 두 명 `4 / 90 90 10 50`이면? "가장 높은 점수"를 하나만 빼는 게 맞는지 문제를 다시 읽어 봐요. 이런 애매한 부분을 찾아내는 것도 실력이에요.

## 3. 빠른 입력: `sys.stdin.readline`

입력이 10만 줄처럼 아주 많으면 `input()`이 느릴 수 있어요. 그럴 때는 이렇게 바꿔요.

```python
import sys
input = sys.stdin.readline

n = int(input())
for _ in range(n):
    a, b = map(int, input().split())
    print(a + b)
```

- `import sys`: 파이썬에 들어 있는 `sys`라는 도구 상자를 꺼내 와요. (`import`는 "가져오기"예요)
- `input = sys.stdin.readline`: 지금부터 `input`이라고 부르면 더 빠른 `sys.stdin.readline`을 쓰라는 뜻이에요. 나머지 코드는 **그대로** 써도 돼요.

### ⚠️ 문자열을 받을 때는 `.rstrip()`

`sys.stdin.readline`은 줄 끝의 **줄바꿈 문자(`\n`)까지** 같이 읽어요. 숫자는 `int()`가 알아서 무시하지만, **문자열**은 끝에 줄바꿈이 붙어 있어요.

```python
import sys
input = sys.stdin.readline

name = input().rstrip()    # 끝의 줄바꿈 제거
```

4장의 `strip()`과 같은 종류인데, 오른쪽(**r**ight) 끝만 지워요.

> 💡 입력이 몇 줄 안 되면 그냥 `input()`을 써도 괜찮아요. **입력이 1만 줄을 넘어가면** `sys.stdin.readline`을 쓰는 습관을 들이세요.

## 4. 제한 조건과 시간: 얼마나 빨라야 할까?

코딩테스트에는 **시간 제한**(보통 1~2초)이 있어요. 정답을 내도 너무 느리면 **시간 초과**로 틀려요.

### 대충 계산하는 법

파이썬은 1초에 **대략 1천만 번** 정도의 간단한 계산을 한다고 생각하면 안전해요. (컴퓨터마다 다르지만, 어림잡기에는 충분해요.)

| 코드 모양 | 계산 횟수 | N = 1,000 | N = 100,000 |
| --- | --- | --- | --- |
| 반복문 하나 | N번 | 1천 번 ✅ | 10만 번 ✅ |
| 반복문 두 개 겹침 (7장 중첩) | N × N번 | 100만 번 ✅ | **100억 번 ❌** |

그래서 **제한 조건을 보면 쓸 수 있는 방법이 보여요.**

- N ≤ 1,000 → 반복문을 두 번 겹쳐도 괜찮아요.
- N ≤ 100,000 → 반복문 두 번 겹치기는 위험해요. 한 번만 돌면서 푸는 방법을 찾아야 해요.

### 숨어 있는 반복문 조심

반복문이 하나처럼 보여도, 안에 **숨은 반복**이 있을 수 있어요.

```python
for x in nums:            # N번
    if x in other_list:   # 리스트의 in은 앞에서부터 하나씩 비교 → 최대 N번
        ...
```

리스트의 `in`, `count()`, `index()`, `remove()`, `min()`, `max()`, `sum()`은 전부 **속에서 리스트를 한 바퀴 도는** 기능이에요. 반복문 안에 넣으면 사실상 반복문 두 개 겹친 것과 같아요.

### 해결: 집합과 딕셔너리

10장에서 "집합과 딕셔너리의 `in`은 바로 찾는다"고 했죠? 그게 여기서 쓰여요.

```python
other_set = set(other_list)    # 한 번만 바꿔 두고
for x in nums:
    if x in other_set:         # 바로 찾음
        ...
```

이 컴퓨터에서 직접 재 보면 차이가 이 정도예요.

| 방법 | 원소 10만 개에서 "있나?"를 1,000번 확인 |
| --- | --- |
| 리스트 `in` | 약 0.4초 |
| 집합 `in` | 약 0.00002초 |

10장 문제 5(결승선)에서 `remove()` 대신 딕셔너리를 쓴 이유가 이거예요.

### 반복문 안에서 고정된 값을 매번 다시 구하지 않기

```python
for x in nums:
    if x == max(nums):    # ❌ max가 매번 리스트를 한 바퀴 돌아요
        ...

biggest = max(nums)       # ✅ 한 번만 구해 두기
for x in nums:
    if x == biggest:
        ...
```
