# 2장: 변수와 자료형

> **이 장의 목표:** 값을 변수에 담아 쓰고, 값의 종류(자료형)를 구분하고, 다른 종류로 바꿀 수 있다.

---

## 1. 변수: 이름표 붙은 상자

**변수**는 값을 담아 두는 **이름표 붙은 상자**예요. 한 번 담아 두면 이름만 불러서 몇 번이고 다시 꺼내 쓸 수 있어요.

```python
age = 25
print(age)
print(age)
```

```
25
25
```

### `=`는 "같다"가 아니라 "넣는다"예요

수학에서 `=`는 "양쪽이 같다"는 뜻이지만, 파이썬에서는 **"오른쪽 값을 왼쪽 상자에 넣어라"**라는 뜻이에요.

```python
age = 25
```

> "25를 `age`라는 상자에 넣어라"

그래서 항상 **오른쪽을 먼저 계산하고, 그 결과를 왼쪽에 넣어요.**

```python
total = 3 + 4      # 3 + 4를 먼저 계산 → 7을 total에 넣음
print(total)
```

```
7
```

### 상자의 값은 바꿀 수 있어요

같은 이름에 새 값을 넣으면 **예전 값은 사라지고** 새 값으로 바뀌어요.

```python
score = 70
print(score)
score = 95
print(score)
```

```
70
95
```

### 자기 자신을 이용해서 바꾸기

이 줄이 처음에는 이상해 보일 거예요.

```python
count = 1
count = count + 1
print(count)
```

```
2
```

수학이라면 `count = count + 1`은 말이 안 되죠. 하지만 파이썬에서는 **오른쪽 먼저**예요.

1. 오른쪽 `count + 1`을 계산해요. 지금 `count`는 1이니까 → `2`
2. 그 결과 `2`를 왼쪽 `count`에 넣어요.

이 모양은 앞으로 정말 많이 나와요. 꼭 기억해 두세요.

### 변수 이름 짓는 규칙

| 규칙 | 되는 예 | 안 되는 예 |
| --- | --- | --- |
| 영어 소문자, 숫자, 밑줄(`_`)로 써요 | `name`, `score2`, `max_speed` | `max-speed` (빼기로 읽힘), `my name` (띄어쓰기) |
| 숫자로 시작하면 안 돼요 | `player1` | `1player` |
| 파이썬이 쓰는 단어는 안 돼요 | `my_class` | `class`, `if`, `for` |
| 대문자와 소문자는 다른 이름이에요 | `age`와 `Age`는 서로 다른 상자 | |

파이썬에서는 여러 단어를 **소문자 + 밑줄**로 이어요. 이걸 **스네이크 케이스**라고 불러요. 뱀처럼 바닥에 붙어서 이어지는 모양이라서요.

```python
running_distance = 5   # ✅ 파이썬 스타일
runningDistance = 5    # 동작은 하지만 파이썬에서는 잘 안 써요
```

> 💡 한글 이름(`나이 = 25`)도 동작은 하지만 쓰지 않아요. 코딩테스트와 실무 코드는 모두 영어 이름을 써요.

### 이름을 잘 지어야 해요

```python
a = 25        # 😕 a가 뭔지 알 수 없어요
age = 25      # 🙂 바로 알 수 있어요
```

## 2. 자료형: 값의 종류

값에는 **종류**가 있어요. 이걸 **자료형(type)**이라고 해요. 처음에는 이 4가지만 알면 돼요.

| 자료형 | 이름 뜻 | 담는 값 | 예 |
| --- | --- | --- | --- |
| `int` | integer, 정수 | 소수점 **없는** 숫자 | `3`, `-10`, `0`, `2026` |
| `float` | 실수 | 소수점 **있는** 숫자 | `3.14`, `65.5`, `-0.5`, `2.0` |
| `str` | string, 문자열 | 글자 (따옴표로 감쌈) | `'안녕'`, `'a'`, `'123'`, `''` |
| `bool` | boolean, 참거짓 | 참 또는 거짓 딱 두 개 | `True`, `False` |

```python
year = 2026          # int
height = 172.5       # float
name = '파이썬'      # str
is_student = True    # bool
```

### 헷갈리기 쉬운 것들

- `2.0`은 `float`예요. 소수점이 **있으면** 뒤가 0이어도 실수예요.
- `'123'`은 `str`이에요. 따옴표가 있으면 숫자처럼 생겨도 **글자**예요.
- `''`(따옴표 안에 아무것도 없음)도 `str`이에요. **빈 문자열**이라고 불러요.
- `True`, `False`는 **첫 글자가 대문자**예요. `true`라고 쓰면 `NameError`가 나요.

### `type()`: 자료형 확인하기

값이 무슨 종류인지 모를 때 `type()`으로 물어볼 수 있어요.

```python
print(type(2026))
print(type(172.5))
print(type('파이썬'))
print(type(True))
print(type('123'))
```

```
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'str'>
```

`<class 'int'>`는 "이 값은 `int` 종류예요"라는 뜻이에요. `class`라는 말은 지금은 신경 쓰지 않아도 돼요.

## 3. 자료형이 왜 중요해요?

같은 `+`라도 **자료형에 따라 하는 일이 달라요.**

```python
print(3 + 4)        # 숫자 + 숫자 → 더하기
print('3' + '4')    # 글자 + 글자 → 이어 붙이기
```

```
7
34
```

`'3' + '4'`는 `7`이 아니라 `'34'`예요! 글자 두 개를 **이어 붙였기** 때문이에요.

그리고 **글자와 숫자는 더할 수 없어요.**

```python
print('3' + 4)
```

```
TypeError: can only concatenate str (not "int") to str
```

`TypeError`는 **자료형이 맞지 않는다**는 에러예요. "글자(str)에는 글자만 이어 붙일 수 있어요. 숫자(int)는 안 돼요"라는 뜻이에요.

## 4. 형변환: 다른 종류로 바꾸기

자료형 이름을 함수처럼 쓰면 값을 **그 종류로 바꿀** 수 있어요. 이걸 **형변환**이라고 해요.

| 쓰는 법 | 하는 일 | 예 | 결과 |
| --- | --- | --- | --- |
| `int(값)` | 정수로 바꾸기 | `int('25')` | `25` |
| `float(값)` | 실수로 바꾸기 | `float('3.5')` | `3.5` |
| `str(값)` | 글자로 바꾸기 | `str(25)` | `'25'` |

```python
text = '25'
number = int(text)
print(number + 1)

price = 3000
message = str(price) + '원'
print(message)
```

```
26
3000원
```

- `int(text)`: 글자 `'25'`를 숫자 `25`로 바꿔서 더하기를 할 수 있게 만들었어요.
- `str(price)`: 숫자 `3000`을 글자 `'3000'`으로 바꿔서 `'원'`과 이어 붙일 수 있게 만들었어요.

> 💡 형변환은 **새 값을 만들어 줄 뿐**이에요. `int(text)`를 해도 `text`는 여전히 `'25'`(글자)예요. 바뀐 값을 쓰려면 `number = int(text)`처럼 변수에 담아야 해요.

### 형변환 주의할 점

```python
print(int(3.9))     # 실수 → 정수: 소수점 아래를 그냥 버려요 (반올림 아님!)
print(float(3))     # 정수 → 실수
print(int('3.5'))   # ❌ 소수점 있는 글자는 바로 int로 못 바꿔요
```

```
3
3.0
ValueError: invalid literal for int() with base 10: '3.5'
```

- `int(3.9)`는 `4`가 아니라 `3`이에요. **버림**이에요.
- `ValueError`는 **값이 이상하다**는 에러예요. `int('안녕')`처럼 숫자로 바꿀 수 없는 글자를 넣어도 나요.

> 이 형변환은 5장(입력 받기)에서 **매일** 쓰게 돼요. 입력은 항상 글자로 들어오거든요.

## 5. 한 줄에 여러 변수 만들기

쉼표로 나누면 한 번에 여러 상자에 값을 넣을 수 있어요.

```python
x, y = 10, 20
print(x, y)
```

```
10 20
```

### 두 변수의 값 바꾸기

`a`와 `b`의 값을 서로 바꾸고 싶다면 어떻게 할까요? 이렇게 하면 **안 돼요.**

```python
a = 1
b = 2
a = b      # a = 2
b = a      # b = 2  (a는 이미 2가 됐으니까!)
print(a, b)
```

```
2 2
```

`a`의 원래 값 `1`이 사라져 버렸어요. 방법은 두 가지예요.

```python
# 방법 1: 임시 상자 쓰기
a = 1
b = 2
temp = a    # a의 값을 잠깐 맡겨 둬요
a = b
b = temp
print(a, b)

# 방법 2: 파이썬식 한 줄
a = 1
b = 2
a, b = b, a
print(a, b)
```

```
2 1
2 1
```

방법 2는 오른쪽 `b, a`(= `2, 1`)를 **먼저 다 계산한 다음** 왼쪽에 넣기 때문에 값이 사라지지 않아요.

## 6. 자주 하는 실수

| 실수 | 결과 | 고친 모습 |
| --- | --- | --- |
| `print('age')` | 글자 `age`가 나옴 | `print(age)`: 변수를 부를 때는 따옴표 없이 |
| `true` | `NameError` | `True` (첫 글자 대문자) |
| `'3' + 4` | `TypeError` | `int('3') + 4` 또는 `'3' + str(4)` |
| `25 = age` | `SyntaxError` | `age = 25`: 상자 이름은 왼쪽 |
| 만들기 전에 쓰기 `print(score)` → 그다음 `score = 90` | `NameError` | 위에서 아래로 실행하니까, 먼저 만들고 나서 써요 |

> **Dart와 비교** (Dart도 같이 공부 중이라면)
> - Dart: `int age = 25;` / `var age = 25;`, 이름은 `runningDistance`
> - 파이썬: `age = 25` (타입을 안 적고, 세미콜론도 없어요), 이름은 `running_distance`
