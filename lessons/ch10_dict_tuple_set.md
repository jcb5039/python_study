# 10장: 딕셔너리·튜플·집합

> **이 장의 목표:** 이름으로 값을 찾는 딕셔너리, 바꿀 수 없는 튜플, 중복 없는 집합을 상황에 맞게 쓸 수 있다.

리스트는 **번호**로 값을 찾았어요. 그런데 "사과 가격이 얼마지?"처럼 **이름**으로 찾고 싶을 때가 많아요. 이 장의 세 가지는 코딩테스트에서 리스트 다음으로 많이 써요. 특히 **딕셔너리로 개수 세기**는 정말 자주 나와요.

| 종류 | 모양 | 한 줄 요약 |
| --- | --- | --- |
| 리스트 | `[1, 2, 3]` | 번호로 찾는 줄 서기 (8장) |
| **딕셔너리** | `{'사과': 1200}` | **이름표**로 찾는 사물함 |
| **튜플** | `(1, 2)` | **바꿀 수 없는** 리스트 |
| **집합** | `{1, 2, 3}` | **중복 없는** 주머니 |

## 1. 딕셔너리: 이름표로 찾는 사물함

**딕셔너리(dict)**는 **키(key)**와 **값(value)**을 짝지어 저장해요. 사전(dictionary)에서 단어(키)를 찾으면 뜻(값)이 나오는 것과 같아요.

```python
prices = {'사과': 1200, '바나나': 800}
print(prices['사과'])
```

```
1200
```

- 중괄호 `{ }` 안에 `키: 값`을 쉼표로 나눠서 써요.
- `딕셔너리[키]`로 값을 꺼내요. 리스트의 `[번호]` 대신 `[키]`를 쓰는 거예요.

### 추가하고 바꾸기

**같은 모양**으로 해요. 키가 없으면 새로 추가, 있으면 값을 바꿔요.

```python
prices = {'사과': 1200, '바나나': 800}
prices['우유'] = 2500     # 없던 키 → 추가
prices['사과'] = 1000     # 있던 키 → 값 바꾸기
print(prices)
```

```
{'사과': 1000, '바나나': 800, '우유': 2500}
```

> 💡 키는 **하나뿐**이에요. 같은 키로 두 번 넣으면 두 개가 생기는 게 아니라 값이 덮어써져요.

### 지우기

```python
del prices['바나나']
```

### 키가 있는지 확인: `in`

```python
print('사과' in prices)
print(1000 in prices)
```

```
True
False
```

`in`은 **키**에서만 찾아요. `1000`은 값이라서 `False`예요.

### 없는 키를 꺼내면 에러: `get`으로 안전하게

```python
prices = {'사과': 1200}
print(prices['딸기'])
```

```
KeyError: '딸기'
```

키가 없을 수도 있으면 `get`을 써요.

```python
print(prices.get('딸기'))       # 없으면 None
print(prices.get('딸기', 0))    # 없으면 0 (원하는 값)
```

```
None
0
```

### 반복하기

```python
prices = {'사과': 1000, '우유': 2500}

for name in prices:                   # 그냥 돌면 키가 나와요
    print(name, prices[name])

for name, price in prices.items():    # 키와 값을 같이
    print(name, price)
```

```
사과 1000
우유 2500
사과 1000
우유 2500
```

| 쓰는 법 | 결과 |
| --- | --- |
| `len(d)` | 키의 개수 |
| `d.keys()` | 키들 |
| `d.values()` | 값들 |
| `d.items()` | (키, 값) 짝들 |

`sum(d.values())`처럼 값들의 합도 구할 수 있어요.

## 2. 딕셔너리로 개수 세기 ⭐

코딩테스트에서 **가장 많이 쓰는** 딕셔너리 패턴이에요. 모양째로 외워 두세요.

```python
counts = {}
for ch in 'banana':
    counts[ch] = counts.get(ch, 0) + 1
print(counts)
```

```
{'b': 1, 'a': 3, 'n': 2}
```

`counts[ch] = counts.get(ch, 0) + 1` 한 줄을 풀어 볼게요.

1. `counts.get(ch, 0)`: 지금까지 센 개수. **처음 보는 글자면 0**
2. `+ 1`: 하나 더해서
3. `counts[ch] = ...`: 다시 저장

| 글자 | `get` 결과 | 저장 후 `counts` |
| --- | --- | --- |
| b | 0 | `{'b': 1}` |
| a | 0 | `{'b': 1, 'a': 1}` |
| n | 0 | `{'b': 1, 'a': 1, 'n': 1}` |
| a | 1 | `{'b': 1, 'a': 2, 'n': 1}` |
| n | 1 | `{'b': 1, 'a': 2, 'n': 2}` |
| a | 2 | `{'b': 1, 'a': 3, 'n': 2}` |

같은 방법으로 단어 개수, 투표 수, 등장 횟수 등을 셀 수 있어요.

### 가장 많이 나온 것 찾기

7장의 "가장 큰 값 찾기" 패턴을 쓰면 돼요.

```python
best = ''
best_count = 0
for key, count in counts.items():
    if count > best_count:
        best = key
        best_count = count
print(best, best_count)
```

```
a 3
```

## 3. 튜플: 바꿀 수 없는 리스트

**튜플(tuple)**은 소괄호 `( )`로 만들어요. 리스트처럼 번호로 꺼낼 수 있지만, **값을 바꿀 수 없어요.**

```python
point = (3, 5)
print(point[0])
point[0] = 10
```

```
3
TypeError: 'tuple' object does not support item assignment
```

### 사실 이미 써 봤어요

괄호 없이 쉼표로 묶어도 튜플이 돼요.

```python
a = 1, 2
print(a)
```

```
(1, 2)
```

- 2장 `a, b = b, a`: 오른쪽 `b, a`가 튜플이에요.
- 9장 `return min(nums), max(nums)`: 튜플을 돌려준 거예요.
- 이번 장 `for name, price in prices.items()`: 짝 하나하나가 튜플이에요.

### 언제 써요?

**한 덩어리로 다니는 값**을 묶을 때 써요. 좌표 `(x, y)`, `(이름, 점수)` 같은 거요.

```python
students = [('민지', 90), ('철수', 85)]
for name, score in students:
    print(name, score)
```

```
민지 90
철수 85
```

> 💡 처음에는 "튜플 = 바꿀 수 없는 리스트, 쉼표로 묶으면 생김" 정도만 알면 충분해요.

## 4. 집합: 중복 없는 주머니

**집합(set)**은 **같은 값을 하나만** 담아요. 순서도 없어요.

```python
s = {3, 1, 3, 2, 1}
print(s)
print(len(s))
```

```
{1, 2, 3}
3
```

### 중복 제거하기 ⭐

리스트를 `set()`으로 감싸면 중복이 사라져요. 코딩테스트에서 가장 많이 쓰는 집합 사용법이에요.

```python
nums = [5, 3, 5, 1, 3]
unique = set(nums)
print(len(unique))           # 서로 다른 값의 개수
print(sorted(unique))        # 중복 없이 정렬된 리스트
```

```
3
[1, 3, 5]
```

> ⚠️ 집합은 **순서가 없어서** 번호로 꺼낼 수 없어요(`s[0]`은 에러). 순서가 필요하면 `sorted()`로 리스트를 만들어요.

### 추가하기와 확인하기

```python
seen = set()          # 빈 집합 (주의: {}는 빈 딕셔너리예요!)
seen.add(1)
seen.add(1)           # 이미 있으면 아무 일도 안 일어나요
print(seen)
print(1 in seen)
```

```
{1}
True
```

### 왜 `in`은 집합에서 쓰는 게 좋아요?

리스트에서 `in`은 **앞에서부터 하나씩** 비교해요. 값이 10만 개면 10만 번 비교할 수도 있어요.
집합과 딕셔너리의 `in`은 **바로** 찾아요. 책의 **목차**에서 쪽 번호를 바로 찾는 것과 같아요.
그래서 "이미 본 값인지 확인"을 여러 번 해야 할 때는 리스트 대신 집합을 써요. 12장에서 다시 다뤄요.

### 집합끼리 계산

| 쓰는 법 | 뜻 | 예 | 결과 |
| --- | --- | --- | --- |
| `a & b` | 교집합 (둘 다 있는 것) | `{1, 2, 3} & {2, 3, 4}` | `{2, 3}` |
| `a \| b` | 합집합 (하나라도 있는 것) | `{1, 2} \| {2, 3}` | `{1, 2, 3}` |
| `a - b` | 차집합 (a에만 있는 것) | `{1, 2, 3} - {2}` | `{1, 3}` |

## 6. 자주 하는 실수

| 실수 | 결과 | 고친 모습 |
| --- | --- | --- |
| 없는 키를 `d[키]`로 꺼냄 | `KeyError` | `d.get(키, 0)` 또는 `if 키 in d:` |
| 개수 세기에서 `counts[ch] += 1`만 씀 | 처음 보는 글자에서 `KeyError` | `counts[ch] = counts.get(ch, 0) + 1` |
| 빈 집합을 `{}`로 만듦 | 빈 **딕셔너리**가 됨 | `set()` |
| 집합에서 `s[0]` | `TypeError` | `sorted(s)[0]` |
| 튜플 값을 바꾸려 함 | `TypeError` | 리스트를 쓰거나 새 튜플을 만들기 |
| `for x in d:`에서 `x`가 값이라고 생각 | 키가 나옴 | 값은 `d[x]` 또는 `.items()` |
