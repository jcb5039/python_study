# 9장: 함수

> **이 장의 목표:** 함수를 직접 만들고, 값을 넣어 부르고, `return`으로 결과를 돌려받을 수 있다.

지금까지 `print()`, `len()`, `int()`, `input()` 같은 **함수**를 이미 많이 썼어요. 이 장에서는 이런 함수를 **직접 만들어요.** 프로그래머스 같은 코딩테스트 사이트는 문제를 **함수 모양**으로 내기 때문에 꼭 알아야 해요.

---

## 1. 함수가 뭐예요?

함수는 **이름 붙은 작업 묶음**이에요. 자판기를 떠올려 보세요.

```
  [돈, 버튼]  →  🏧 자판기  →  [음료]
   넣는 것        하는 일       나오는 것
```

- **넣는 것**: 함수에 주는 값 (매개변수)
- **하는 일**: 함수 안의 코드
- **나오는 것**: 함수가 돌려주는 값 (반환값)

자판기 안에서 무슨 일이 일어나는지 몰라도, 넣고 누르면 음료가 나와요. 함수도 한 번 만들어 두면 **이름만 불러서** 몇 번이고 쓸 수 있어요.

### 왜 만들어요?

```python
# 함수 없이: 같은 코드를 세 번
print('=' * 10)
print('1주차')
print('=' * 10)
print('=' * 10)
print('2주차')
print('=' * 10)
```

```python
# 함수로: 한 번 만들고 이름으로 부르기
def title(text):
    print('=' * 10)
    print(text)
    print('=' * 10)

title('1주차')
title('2주차')
```

- 같은 코드를 **반복해서 쓰지 않아도** 돼요.
- 고칠 때 **한 군데만** 고치면 돼요.
- 이름만 봐도 **무슨 일을 하는지** 알 수 있어요.

## 2. 함수 만들기와 부르기

```python
def say_hello():
    print('안녕하세요')
    print('반가워요')

say_hello()
say_hello()
```

```
안녕하세요
반가워요
안녕하세요
반가워요
```

### 모양 뜯어보기

```python
def 함수이름(매개변수):
    할 일
```

| 부분 | 뜻 |
| --- | --- |
| `def` | **def**ine(정의하다). "지금부터 함수를 만들어요" |
| `say_hello` | 함수 이름. 변수 이름 규칙과 같아요 (소문자 + 밑줄) |
| `()` | 넣는 값을 받을 자리. 없으면 비워 둬요 |
| `:` + 4칸 들여쓰기 | `if`, `for`와 같아요. 들여쓴 부분이 함수의 몸통 |

### 만드는 것과 부르는 것은 달라요

```python
def say_hello():
    print('안녕하세요')
```

이것만 쓰고 실행하면 **아무것도 출력되지 않아요.** `def`는 "이런 함수가 있어요"라고 **레시피를 적어 둔 것**뿐이에요. 실제로 요리하려면 **이름 뒤에 괄호를 붙여서 불러야** 해요.

```python
say_hello()      # ← 이게 '부르기(호출)'
```

> ⚠️ 함수는 **부르기 전에 먼저 만들어야** 해요. 파이썬은 위에서 아래로 읽으니까, `def`가 부르는 줄보다 위에 있어야 해요.

## 3. 매개변수: 값을 넣어 주기

괄호 안에 이름을 쓰면, 부를 때 넣은 값을 그 이름으로 받아요.

```python
def greet(name):
    print(f'안녕, {name}!')

greet('민지')
greet('철수')
```

```
안녕, 민지!
안녕, 철수!
```

`greet('민지')`를 부르면 `name`이라는 상자에 `'민지'`가 들어간 채로 함수가 실행돼요.

| 용어 | 뜻 | 예 |
| --- | --- | --- |
| **매개변수** | 함수를 만들 때 정해 둔 **빈 상자 이름** | `name` |
| **인자** | 함수를 부를 때 넣는 **실제 값** | `'민지'` |

### 여러 개 넣기

쉼표로 나눠요. **순서대로** 들어가요.

```python
def introduce(name, age):
    print(f'{name}: {age}살')

introduce('민지', 25)
```

```
민지: 25살
```

개수가 안 맞으면 에러가 나요.

```python
introduce('민지')
```

```
TypeError: introduce() missing 1 required positional argument: 'age'
```

"`age` 자리에 넣을 값이 하나 빠졌어요"라는 뜻이에요.

### 기본값

매개변수에 `=값`을 써 두면, 부를 때 생략했을 때 그 값을 써요.

```python
def add(a, b=10):
    return a + b

print(add(1))       # b를 안 넣음 → 10
print(add(1, 2))    # b에 2
```

```
11
3
```

## 4. `return`: 결과 돌려주기

이 장에서 **가장 중요한 내용**이에요.

```python
def add(a, b):
    return a + b

result = add(3, 5)
print(result)
print(add(10, 20) * 2)
```

```
8
60
```

`return 값`은 **"이 값을 부른 곳으로 돌려줘"**라는 뜻이에요. `add(3, 5)`를 부른 자리가 **결과값 `8`로 바뀐다**고 생각하면 돼요.

```python
result = add(3, 5)
#        ↓ 함수가 끝나면 이 자리가 8로 바뀜
result = 8
```

그래서 돌려받은 값을 변수에 담거나, 다시 계산에 쓰거나, 다른 함수에 넣을 수 있어요.

### ⚠️ `print`와 `return`은 완전히 달라요

처음 배울 때 가장 많이 헷갈리는 부분이에요.

```python
def add_print(a, b):
    print(a + b)       # 화면에 보여 주기만 함

def add_return(a, b):
    return a + b       # 부른 곳에 값을 돌려줌

x = add_print(3, 5)
y = add_return(3, 5)
print('x:', x)
print('y:', y)
```

```
8
x: None
y: 8
```

- `add_print`는 화면에 `8`을 **보여 주긴 했지만**, 돌려준 값이 없어서 `x`에는 **`None`**이 들어갔어요.
- `add_return`은 화면에는 아무것도 안 보여 줬지만, `y`에 **`8`이 들어갔어요.**

| | `print` | `return` |
| --- | --- | --- |
| 누구에게? | **사람**에게 화면으로 보여 줌 | **코드**에게 값을 건네줌 |
| 받은 값을 다시 쓸 수 있나? | ❌ | ✅ |
| 비유 | 안내 방송 (들리기만 함) | 자판기 (손에 음료가 떨어짐) |

> 💡 **코딩테스트의 함수형 문제(프로그래머스)는 무조건 `return`이에요.** `print`로 답을 보여 주면 틀린 답이 돼요. 채점기가 함수가 돌려준 값을 받아서 비교하거든요. 이 강의의 9~11장 문제도 똑같아요.

### `None`: 아무것도 없음

`return`이 없는 함수는 끝나면 자동으로 **`None`**을 돌려줘요. `None`은 "아무 값도 없음"을 뜻하는 특별한 값이에요. 2장 문제에서 빈칸에 써 있던 그 `None`이에요.

### `return`을 만나면 함수는 바로 끝나요

```python
def check_sign(n):
    if n < 0:
        return '음수'
    return '양수 또는 0'

print(check_sign(-1))
print(check_sign(3))
```

```
음수
양수 또는 0
```

`n`이 `-1`이면 `return '음수'`에서 **함수가 끝나서** 아래 줄은 실행되지 않아요. 그래서 `else`를 안 써도 돼요. 7장의 `break`가 반복문을 끝내는 것처럼, `return`은 **함수 전체**를 끝내요.

### 값 여러 개 돌려주기

쉼표로 나눠서 돌려주면, 받을 때도 쉼표로 나눠서 받아요.

```python
def min_max(nums):
    return min(nums), max(nums)

low, high = min_max([3, 1, 2])
print(low, high)
```

```
1 3
```

5장의 `a, b = map(...)`과 같은 방식이에요. 이렇게 묶인 값의 정체(튜플)는 10장에서 배워요.

## 5. 함수 안의 변수는 함수 안에서만 살아요

```python
def make_box():
    x = 1
    print(x)

make_box()
print(x)
```

```
1
NameError: name 'x' is not defined
```

함수 **안에서** 만든 변수는 함수가 끝나면 **사라져요.** 이걸 **지역 변수**라고 해요. 함수 밖에서 그 값이 필요하면 `return`으로 돌려받아야 해요.

매개변수도 지역 변수예요. 그래서 다른 함수들이 똑같이 `n`, `nums` 같은 이름을 써도 서로 섞이지 않아요.

## 6. 함수 안에서 함수 부르기

만든 함수를 다른 함수 안에서 부를 수 있어요. 작은 함수를 조립해서 큰 일을 하는 거예요.

```python
def is_even(n):
    return n % 2 == 0

def count_even(nums):
    count = 0
    for x in nums:
        if is_even(x):
            count += 1
    return count

print(count_even([1, 2, 3, 4, 6]))
```

```
3
```

`is_even(x)`가 `True`나 `False`를 **돌려주기 때문에** `if`에 바로 쓸 수 있어요. `print`로 만들었다면 이렇게 못 써요.

## 8. 자주 하는 실수

| 실수 | 결과 | 고친 모습 |
| --- | --- | --- |
| `return` 대신 `print` | 돌려받으면 `None` | `return 값` |
| `def`만 쓰고 안 부름 | 아무것도 안 일어남 | `함수이름()` |
| 부를 때 괄호 빠뜨림 `say_hello` | 아무것도 안 일어남 | `say_hello()` |
| 함수를 만들기 전에 부름 | `NameError` | `def`를 위에 |
| 반복문 **안에** `return` | 첫 바퀴에서 함수가 끝남 | 다 돈 다음 반복문 **밖에서** `return` |
| 함수 안 변수를 밖에서 씀 | `NameError` | `return`으로 돌려받기 |
| 인자 개수가 다름 | `TypeError: missing ... argument` | 매개변수 개수에 맞추기 |

> ⚠️ "반복문 안의 `return`"은 정말 많이 해요. 들여쓰기 한 칸 차이로 결과가 완전히 달라져요.
> ```python
> def total(nums):
>     s = 0
>     for x in nums:
>         s += x
>         return s    # ❌ 첫 값만 더하고 끝남
>     return s        # ✅ 이 위치여야 함
> ```
