# 3장: 연산자

> **이 장의 목표:** 숫자를 계산하고, 두 값을 비교하고, 여러 조건을 합칠 수 있다.

**연산자**는 계산을 시키는 기호예요. `+`, `-` 같은 것들이요. 코딩테스트 문제의 절반은 결국 "이 값을 어떻게 계산하지?"라서 이 장이 아주 중요해요.

---

## 1. 산술 연산자: 계산하기

| 기호 | 뜻 | 예 | 결과 |
| --- | --- | --- | --- |
| `+` | 더하기 | `7 + 2` | `9` |
| `-` | 빼기 | `7 - 2` | `5` |
| `*` | 곱하기 | `7 * 2` | `14` |
| `/` | 나누기 | `7 / 2` | `3.5` |
| `//` | 몫 (나눈 뒤 소수점 버림) | `7 // 2` | `3` |
| `%` | 나머지 | `7 % 2` | `1` |
| `**` | 거듭제곱 | `2 ** 10` | `1024` |

### `/` 나누기는 항상 실수(float)예요

```python
print(10 / 2)
print(7 / 2)
```

```
5.0
3.5
```

`10 / 2`가 딱 떨어지는데도 `5`가 아니라 `5.0`이에요. 파이썬의 `/`는 **항상 float**를 돌려줘요. 정수 결과가 필요하면 `//`를 써요.

### `//` 몫과 `%` 나머지

초등학교 때 배운 나눗셈을 떠올려 보세요.

> 7 ÷ 2 = 3 ... 1 (몫 3, 나머지 1)

```python
print(7 // 2)   # 몫
print(7 % 2)    # 나머지
```

```
3
1
```

`%`는 "퍼센트"가 아니라 **나머지**예요. 처음엔 어색하지만 코딩테스트에서 정말 자주 써요.

### 몫과 나머지는 이런 데 써요

**1. 시간 바꾸기**: 375초는 몇 분 몇 초일까요?

```python
seconds = 375
minutes = seconds // 60    # 60초씩 몇 묶음? → 6
rest = seconds % 60        # 묶고 남은 초 → 15
print(minutes, '분', rest, '초')
```

```
6 분 15 초
```

**2. 짝수/홀수 구분**: 2로 나눈 나머지가 0이면 짝수, 1이면 홀수예요.

```python
print(10 % 2)
print(7 % 2)
```

```
0
1
```

**3. 일의 자리 꺼내기**: 10으로 나눈 나머지는 일의 자리, 몫은 일의 자리를 뗀 나머지예요.

```python
n = 1234
print(n % 10)     # 일의 자리
print(n // 10)    # 일의 자리를 뗀 나머지
```

```
4
123
```

### 계산 순서

수학처럼 **곱하기·나누기가 더하기·빼기보다 먼저**예요. 먼저 하고 싶은 부분은 괄호로 감싸요.

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
```

```
14
20
```

> 💡 순서가 헷갈리면 그냥 괄호를 쳐요. 괄호가 많아도 틀리지는 않아요.

### 실수 계산은 아주 조금 틀릴 수 있어요

```python
print(0.1 + 0.2)
```

```
0.30000000000000004
```

컴퓨터가 실수를 저장하는 방식 때문에 생기는 아주 작은 오차예요. 버그가 아니라 모든 프로그래밍 언어에서 똑같이 생겨요. 실수를 보여 줄 때는 `round()`로 반올림하면 돼요.

```python
print(round(0.1 + 0.2, 2))    # 소수점 2자리까지 반올림
print(round(3.14159, 2))
```

```
0.3
3.14
```

> 💡 `round(값, 자릿수)`: 자릿수를 빼고 `round(3.7)`처럼 쓰면 정수로 반올림해요.

## 2. 문자열에도 `+`와 `*`를 쓸 수 있어요

```python
print('파이' + '썬')    # 이어 붙이기
print('하' * 3)        # 반복하기
print('-' * 10)        # 구분선 만들 때 자주 써요
```

```
파이썬
하하하
----------
```

`글자 * 숫자`는 글자를 **그 숫자만큼 반복**해요. 하지만 `글자 + 숫자`는 2장에서 본 것처럼 `TypeError`예요.

## 3. 복합 대입 연산자: 줄여 쓰기

2장에서 `count = count + 1` 모양을 배웠어요. 이걸 줄여 쓸 수 있어요.

| 줄여 쓴 모양 | 원래 모양 |
| --- | --- |
| `x += 3` | `x = x + 3` |
| `x -= 3` | `x = x - 3` |
| `x *= 3` | `x = x * 3` |
| `x //= 3` | `x = x // 3` |
| `x %= 3` | `x = x % 3` |

```python
total = 0
total += 500
total += 300
print(total)
```

```
800
```

> **Dart와 비교:** 파이썬에는 `x++`가 **없어요.** `x += 1`이라고 써야 해요.

---

## 4. 비교 연산자: 두 값 비교하기

비교 연산자의 결과는 항상 `True` 또는 `False`예요. 질문에 "네/아니요"로 답하는 것과 같아요.

| 기호 | 뜻 | 예 | 결과 |
| --- | --- | --- | --- |
| `==` | 같다 | `3 == 3` | `True` |
| `!=` | 다르다 | `3 != 3` | `False` |
| `>` | 크다 | `5 > 3` | `True` |
| `<` | 작다 | `5 < 3` | `False` |
| `>=` | 크거나 같다 | `5 >= 5` | `True` |
| `<=` | 작거나 같다 | `4 <= 5` | `True` |

```python
age = 20
print(age >= 19)
print(age == 30)
```

```
True
False
```

### ⚠️ `=`와 `==`는 완전히 달라요

- `=` 하나: **넣기** (`age = 20`: age에 20을 넣어라)
- `==` 두 개: **같은지 물어보기** (`age == 20`: age가 20이야?)

처음 배울 때 가장 많이 헷갈리는 부분이에요.

### 비교 결과도 변수에 담을 수 있어요

```python
score = 85
passed = score >= 60
print(passed)
```

```
True
```

### 범위를 한 번에 비교하기

파이썬은 수학처럼 범위를 이어서 쓸 수 있어요.

```python
x = 5
print(1 < x < 10)    # x가 1보다 크고 10보다 작아?
```

```
True
```

## 5. 논리 연산자: 조건 합치기

여러 조건을 합칠 때 써요.

| 연산자 | 뜻 | 언제 True? |
| --- | --- | --- |
| `and` | 그리고 | 양쪽이 **모두** True일 때 |
| `or` | 또는 | 양쪽 중 **하나라도** True일 때 |
| `not` | 반대로 | True ↔ False를 뒤집음 |

```python
age = 20
has_ticket = True

print(age >= 19 and has_ticket)    # 성인이고 표가 있어?
print(age < 13 or age >= 65)       # 어린이거나 노인이야?
print(not has_ticket)              # 표가 없어?
```

```
True
False
False
```

### 표로 정리

| A | B | `A and B` | `A or B` |
| --- | --- | --- | --- |
| True | True | True | True |
| True | False | False | True |
| False | True | False | True |
| False | False | False | False |

> 💡 `and`는 엄격한 문지기(둘 다 통과해야 들어감), `or`는 너그러운 문지기(하나만 통과해도 들어감)라고 생각하면 쉬워요.

## 6. 자주 하는 실수

| 실수 | 결과 | 고친 모습 |
| --- | --- | --- |
| `if x = 3` 처럼 비교에 `=` | `SyntaxError` | `x == 3` |
| `10 / 2`가 `5`일 거라고 생각 | `5.0` (float) | 정수가 필요하면 `10 // 2` |
| `x++` | `SyntaxError` | `x += 1` |
| `7 % 2`를 퍼센트로 생각 | `1` | `%`는 나머지 |
| `2 + 3 * 4`를 `20`이라고 생각 | `14` | 곱하기 먼저. `(2 + 3) * 4` |
| `and`, `or` 대신 `&&`, `\|\|` (다른 언어 습관) | `SyntaxError` | 파이썬은 영어 단어 `and`, `or`, `not` |
