# 7장: 반복문

> **이 장의 목표:** 같은 일을 여러 번 반복하고, 반복하면서 합계나 개수를 구할 수 있다.

"1부터 100까지 더하기"를 `print`로 하려면 100줄을 써야 할까요? **반복문**을 쓰면 몇 줄이면 돼요. 코딩테스트 문제는 거의 전부 반복문을 써요.

---

## 1. `for`와 `range`: 정해진 횟수만큼 반복

```python
for i in range(5):
    print('안녕')
```

```
안녕
안녕
안녕
안녕
안녕
```

`print('안녕')`을 5번 실행했어요.

### 모양 뜯어보기

```python
for 변수 in range(횟수):
    반복할 코드
```

- `range(5)`: 0, 1, 2, 3, 4 라는 **숫자 5개를 차례로** 만들어 줘요.
- `for i in ...`: 그 숫자를 **하나씩 꺼내서 `i`에 넣고**, 블록을 한 번 실행해요. 숫자가 다 떨어지면 끝나요.
- 6장의 `if`처럼 콜론 `:`과 4칸 들여쓰기가 필요해요.

`i`에 무엇이 들어가는지 직접 보면 이해가 쉬워요.

```python
for i in range(5):
    print(i)
```

```
0
1
2
3
4
```

| 반복 | `i`의 값 | 출력 |
| --- | --- | --- |
| 1번째 | 0 | 0 |
| 2번째 | 1 | 1 |
| 3번째 | 2 | 2 |
| 4번째 | 3 | 3 |
| 5번째 | 4 | 4 |

> ⚠️ `range(5)`는 **0부터 4까지**예요. 5는 들어가지 않아요. 4장 슬라이싱의 "끝 번호는 포함하지 않는다"와 같은 규칙이에요.

### `range`의 세 가지 모양

| 모양 | 뜻 | 예 | 만들어지는 숫자 |
| --- | --- | --- | --- |
| `range(끝)` | 0부터 끝-1까지 | `range(5)` | 0, 1, 2, 3, 4 |
| `range(시작, 끝)` | 시작부터 끝-1까지 | `range(1, 6)` | 1, 2, 3, 4, 5 |
| `range(시작, 끝, 간격)` | 간격만큼 건너뛰며 | `range(0, 10, 2)` | 0, 2, 4, 6, 8 |

**1부터 N까지**가 필요하면 `range(1, N + 1)`이라고 써요. 코딩테스트에서 정말 자주 쓰는 모양이에요.

거꾸로 세려면 간격을 음수로 줘요.

```python
for i in range(5, 0, -1):
    print(i)
```

```
5
4
3
2
1
```

### 변수 `i`를 안 쓸 때는 `_`

반복 횟수만 필요하고 `i` 값은 안 쓸 때는 관례적으로 `_`(밑줄)을 써요. "이 값은 안 써요"라는 표시예요.

```python
for _ in range(3):
    print('파이팅')
```

## 2. 반복의 기본 패턴 3가지

이 세 가지는 **모양째로 외워 두세요.** 코딩테스트 문제 대부분이 이 패턴의 변형이에요.

### 패턴 1: 합계 구하기 (누적)

**반복문 밖에서 0으로 시작**하고, 반복하면서 계속 더해요.

```python
total = 0                   # 1. 바구니를 비워 두고
for i in range(1, 11):
    total += i              # 2. 하나씩 담고
print(total)                # 3. 다 끝나면 확인
```

```
55
```

| 반복 | `i` | `total` |
| --- | --- | --- |
| 시작 | | 0 |
| 1번째 | 1 | 1 |
| 2번째 | 2 | 3 |
| 3번째 | 3 | 6 |
| ... | ... | ... |
| 10번째 | 10 | 55 |

> ⚠️ `total = 0`을 반복문 **안에** 넣으면 매번 0으로 초기화돼서 마지막 값만 남아요. `print(total)`을 반복문 **안에** 넣으면 중간 결과가 10번 출력돼요. **들여쓰기 위치**가 정말 중요해요.

### 패턴 2: 개수 세기

조건에 맞을 때만 1씩 늘려요.

```python
count = 0
for i in range(1, 101):
    if i % 7 == 0:
        count += 1
print(count)
```

```
14
```

1부터 100 중 7의 배수는 14개예요.

### 패턴 3: 가장 큰 값 찾기

"지금까지 본 것 중 가장 큰 값"을 기억해 두고, 더 큰 게 나오면 바꿔요.

```python
biggest = 0
for _ in range(3):
    n = int(input())
    if n > biggest:
        biggest = n
print(biggest)
```

```
4       ← 입력
9       ← 입력
2       ← 입력
9
```

> 💡 입력에 음수가 있을 수 있으면 `biggest = 0`으로 시작하면 안 돼요(전부 음수면 0이 나와 버려요). 그럴 때는 **첫 번째 값으로 시작**해요.

## 3. 문자열을 한 글자씩 반복하기

`for`는 `range` 말고 **문자열**도 돌 수 있어요. 글자를 하나씩 꺼내 줘요.

```python
for ch in 'abc':
    print(ch)
```

```
a
b
c
```

```python
word = 'banana'
count = 0
for ch in word:
    if ch == 'a':
        count += 1
print(count)
```

```
3
```

4장의 `count()` 메서드와 같은 일을 직접 구현한 거예요.

## 4. 입력을 여러 줄 받기

코딩테스트에 정말 자주 나오는 입력 모양이에요.

```
3          ← 첫째 줄: 앞으로 몇 줄이 올지
10 20      ← 둘째 줄부터 그 개수만큼
5 5
1 2
```

```python
n = int(input())
for _ in range(n):
    a, b = map(int, input().split())
    print(a + b)
```

```
30
10
3
```

**첫 줄에서 개수를 받고, 그 개수만큼 반복하면서 `input()`을 부르는** 모양이에요. 5장에서는 줄 수가 정해져 있어서 `input()`을 직접 몇 번 썼는데, 이제는 줄 수가 입력에 따라 달라져도 돼요.

## 5. `while`: 조건이 참인 동안 반복

`for`는 **횟수가 정해졌을 때**, `while`은 **언제 끝날지 모를 때** 써요.

```python
n = 1
while n <= 5:
    print(n)
    n += 1
```

```
1
2
3
4
5
```

```python
while 조건:
    반복할 코드
```

1. 조건을 검사해요. True면 블록을 실행해요.
2. 블록이 끝나면 **다시 1번으로** 돌아가서 조건을 검사해요.
3. 조건이 False가 되면 반복을 끝내요.

### ⚠️ 무한 반복 조심

```python
n = 1
while n <= 5:
    print(n)
    # n += 1 을 빼먹음!
```

`n`이 계속 1이라서 조건이 영원히 True예요. `1`이 끝없이 출력돼요. 이럴 때는 터미널에서 **`Ctrl + C`**를 누르면 멈춰요. `while`을 쓸 때는 **조건이 언젠가 False가 되는지** 꼭 확인하세요.

### `while`이 어울리는 예: 자릿수 다루기

3장에서 `% 10`으로 일의 자리를 꺼내고, `// 10`으로 일의 자리를 지웠죠? 이걸 숫자가 0이 될 때까지 반복하면 **각 자리 숫자의 합**을 구할 수 있어요. 몇 자리인지 모르니까 `while`이 딱이에요.

```python
n = 1234
total = 0
while n > 0:
    total += n % 10    # 일의 자리를 더하고
    n //= 10           # 일의 자리를 지워요
print(total)
```

```
10
```

| 반복 | `n % 10` | `total` | `n` (지운 뒤) |
| --- | --- | --- | --- |
| 1번째 | 4 | 4 | 123 |
| 2번째 | 3 | 7 | 12 |
| 3번째 | 2 | 9 | 1 |
| 4번째 | 1 | 10 | 0 → 조건 False, 끝 |

## 6. `break`와 `continue`

### `break`: 반복 당장 그만

```python
while True:
    n = int(input())
    if n == 0:
        break
    print(n * 2)
print('끝')
```

```
3       ← 입력
6
5       ← 입력
10
0       ← 입력
끝
```

`while True`는 조건이 항상 True라서 원래는 무한 반복이에요. 그 안에서 `break`를 만나면 **반복문을 즉시 빠져나가요.** "0이 나올 때까지 입력받기" 같은 문제에서 이렇게 써요.

### `continue`: 이번 차례만 건너뛰기

```python
for i in range(1, 6):
    if i == 3:
        continue
    print(i)
```

```
1
2
4
5
```

`continue`를 만나면 블록의 남은 부분을 건너뛰고 **다음 차례로** 넘어가요. 반복을 끝내는 건 아니에요.

| | 하는 일 | 비유 |
| --- | --- | --- |
| `break` | 반복문 전체를 끝냄 | 운동장 돌다가 집에 가기 |
| `continue` | 이번 바퀴만 건너뜀 | 이번 바퀴는 쉬고 다음 바퀴부터 다시 |

## 7. 반복문 안의 반복문 (중첩)

반복문 안에 반복문을 넣으면, **바깥이 한 번 돌 때 안쪽은 처음부터 끝까지** 다 돌아요.

```python
for i in range(1, 4):
    for j in range(1, 3):
        print(i, j)
```

```
1 1
1 2
2 1
2 2
3 1
3 2
```

시계를 생각하면 쉬워요. 바깥 반복이 **시침**, 안쪽 반복이 **분침**이에요. 분침이 한 바퀴 다 돌아야 시침이 한 칸 움직여요.

### `print`의 줄바꿈 막기: `end`

`print`는 원래 출력한 뒤 줄을 바꿔요. `end=''`를 넣으면 줄을 바꾸지 않아요.

```python
for i in range(3):
    print(i, end=' ')
print()
```

```
0 1 2
```

`end=' '`는 "출력하고 나서 줄바꿈 대신 띄어쓰기를 붙여"라는 뜻이에요. 마지막 `print()`는 줄을 한 번 바꿔 줘요.

### 별 찍기

```python
n = 3
for i in range(1, n + 1):
    print('*' * i)
```

```
*
**
***
```

3장에서 배운 `글자 * 숫자`(반복)를 쓰면 반복문 하나로 돼요.

## 8. 자주 하는 실수

| 실수 | 결과 | 고친 모습 |
| --- | --- | --- |
| 1부터 10까지인데 `range(10)` | 0~9 | `range(1, 11)` |
| `total = 0`을 반복문 안에 씀 | 매번 0으로 초기화 | 반복문 위에 |
| `print(total)`을 반복문 안에 씀 | 중간 결과가 여러 번 출력 | 들여쓰기를 빼서 반복문 밖으로 |
| `while`에서 변수를 안 바꿈 | 무한 반복 | 조건이 언젠가 False가 되게. 멈출 땐 `Ctrl + C` |
| `for i in 5:` | `TypeError` | `for i in range(5):` |
| 콜론, 들여쓰기 빠짐 | `SyntaxError`, `IndentationError` | 6장과 똑같이 |

> 💡 결과가 이상하면 반복문 안에 `print(i, total)`처럼 **중간 값을 출력**해 보세요. 표로 그려 본 것처럼 값이 어떻게 바뀌는지 보여요. 이게 가장 쉬운 디버깅 방법이에요.
