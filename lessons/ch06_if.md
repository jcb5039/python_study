# 6장: 조건문

> **이 장의 목표:** 조건에 따라 다른 코드를 실행하고, 들여쓰기로 코드 덩어리를 만들 수 있다.

지금까지 프로그램은 위에서 아래로 **모든 줄을** 실행했어요. 이 장부터는 **"만약 ~라면 이걸 하고, 아니면 저걸 해"**처럼 갈림길을 만들 수 있어요.

---

## 1. `if`: 만약 ~라면

```python
age = 20
if age >= 19:
    print('성인이에요')
print('끝')
```

```
성인이에요
끝
```

`age`를 `15`로 바꿔서 실행하면 이렇게 나와요.

```
끝
```

`age >= 19`가 `False`라서 `print('성인이에요')`를 **건너뛰었어요.**

### 모양 뜯어보기

```python
if 조건:
    조건이 True일 때 실행할 코드
```

| 부분 | 뜻 |
| --- | --- |
| `if` | "만약" |
| `조건` | `True` 또는 `False`가 나오는 식 (3장의 비교 연산자) |
| `:` (콜론) | "조건 끝, 이제 할 일이 나와요"라는 표시. **빼먹으면 에러** |
| 들여쓴 줄 | 조건이 True일 때만 실행되는 코드 덩어리 |

---

## 2. 들여쓰기: 파이썬의 코드 덩어리

1장에서 "줄 앞에 아무 이유 없이 띄어쓰기를 넣으면 에러"라고 했죠? 이제 **이유가 생겼어요.**

`if` 아래에서 **띄어쓰기 4칸** 들여쓴 줄들이 **"if에 속한 코드 덩어리"**예요. 이 덩어리를 **블록**이라고 불러요.

```python
score = 50
if score >= 60:
    print('합격')        # ┐ if 블록
    print('축하해요')    # ┘ (조건이 True일 때만)
print('채점 끝')         # if 밖 (항상 실행)
```

```
채점 끝
```

들여쓰기를 **멈추는 순간** 블록이 끝나요. `print('채점 끝')`은 들여쓰지 않았으니 `if`와 상관없이 항상 실행돼요.

> 💡 VS Code에서 `:` 뒤에 엔터를 치면 자동으로 4칸 들여써 줘요. `Tab` 키를 눌러도 4칸이 들어가요. 블록에서 나올 때는 `Shift + Tab` 또는 백스페이스를 써요.

### 들여쓰기 에러

**콜론 다음 줄을 들여쓰지 않으면:**

```python
x = 5
if x > 3:
print(x)
```

```
IndentationError: expected an indented block after 'if' statement on line 2
```

"2번째 줄 if 다음에 들여쓴 블록이 있어야 하는데 없어요"라는 뜻이에요.

**같은 블록인데 칸 수가 다르면:**

```python
x = 5
if x > 3:
    print(1)
  print(2)
```

```
IndentationError: unindent does not match any outer indentation level
```

같은 블록의 줄은 **칸 수가 정확히 같아야** 해요. 항상 4칸으로 맞추세요.

> **Dart와 비교:** Dart는 `{ }` 중괄호로 블록을 만들고 들여쓰기는 보기 좋으라고 하는 거예요. 파이썬은 **들여쓰기 자체가 블록**이에요. 중괄호가 없어요.

---

## 3. `else`: 아니면

```python
age = 15
if age >= 19:
    print('성인이에요')
else:
    print('미성년자예요')
```

```
미성년자예요
```

- 조건이 `True`면 `if` 블록, `False`면 `else` 블록 중 **딱 하나만** 실행돼요.
- `else`에는 조건을 쓰지 않아요. "나머지 전부"라는 뜻이니까요.
- `else` 뒤에도 콜론 `:`을 붙여요.

### 짝수/홀수 판별

3장에서 배운 `% 2`와 합치면 이렇게 돼요.

```python
n = int(input())
if n % 2 == 0:
    print('짝수')
else:
    print('홀수')
```

---

## 4. `elif`: 아니면 만약

갈림길이 셋 이상이면 `elif`(**el**se **if**의 줄임말)를 써요.

```python
score = 85
if score >= 90:
    print('A')
elif score >= 80:
    print('B')
elif score >= 70:
    print('C')
else:
    print('F')
```

```
B
```

### 위에서부터 차례대로 검사해요

파이썬은 조건을 **위에서부터 하나씩** 검사하다가, **처음으로 True인 블록 하나만** 실행하고 나머지는 전부 건너뛰어요.

`score = 85`일 때:

1. `85 >= 90`? False → 다음으로
2. `85 >= 80`? **True** → `'B'` 출력 → **끝** (아래는 보지도 않아요)

그래서 `elif score >= 80`이라고만 써도 "80 이상 90 미만"이라는 뜻이 돼요. 90 이상이었다면 이미 위에서 걸렸을 테니까요.

### ⚠️ 순서가 중요해요

```python
score = 95
if score >= 70:
    print('C')
elif score >= 90:
    print('A')
```

```
C
```

95점인데 `C`가 나왔어요! `95 >= 70`이 먼저 True가 돼서 바로 끝났기 때문이에요. **범위가 좁은(까다로운) 조건을 위에** 써야 해요.

### `if`를 여러 개 쓰는 것과는 달라요

```python
score = 95
if score >= 90:
    print('A')
if score >= 80:
    print('B')
```

```
A
B
```

`if`를 따로따로 쓰면 **각각 따로 검사**해서 둘 다 실행될 수 있어요. 여러 개 중 **하나만** 고르려면 `if`, `elif`, `else`를 이어서 써요.

## 5. 조건 합치기

3장의 `and`, `or`, `not`을 조건에 그대로 쓸 수 있어요.

```python
age = 25
has_ticket = True
if age >= 19 and has_ticket:
    print('입장 가능')
else:
    print('입장 불가')
```

범위 조건은 이어서 쓰면 편해요.

```python
hour = 14
if 9 <= hour < 18:
    print('영업 중')
```

`in`도 조건에 쓸 수 있어요.

```python
answer = input()
if 'y' in answer:
    print('yes로 볼게요')
```

## 6. 조건문 안의 조건문 (중첩)

블록 안에 또 `if`를 넣을 수 있어요. 들여쓰기가 한 단계 더 깊어져요(8칸).

```python
age = 25
is_member = True
if age >= 19:
    if is_member:
        print('성인 회원')
    else:
        print('성인 비회원')
else:
    print('미성년자')
```

```
성인 회원
```

중첩이 깊어지면 읽기 어려워요. `and`로 합칠 수 있으면 합치는 게 좋아요.

---

## 7. 한 줄 조건 표현식

값을 둘 중 하나로 고를 때는 한 줄로 쓸 수 있어요.

```python
n = 7
label = '짝수' if n % 2 == 0 else '홀수'
print(label)
```

```
홀수
```

> `참일 때 값 if 조건 else 거짓일 때 값`

읽을 때는 "**짝수**야, 만약 `n % 2 == 0`이면. 아니면 **홀수**"라고 읽으면 돼요. 간단히 값만 고를 때만 쓰고, 여러 줄의 일을 할 때는 보통 `if`/`else`를 써요.

## 8. `pass`: 아무것도 안 하기

블록 안에 아직 쓸 코드가 없을 때, 비워 두면 들여쓰기 에러가 나요. 그럴 때 **"아무것도 안 해"**라는 뜻의 `pass`를 써 둬요.

```python
x = 5
if x > 3:
    pass    # TODO: 나중에 채울 예정
```

9장부터 문제 파일에서 `pass`를 자주 보게 될 거예요. "여기를 채우세요"라는 표시예요.

---

## 9. 자주 하는 실수

| 실수 | 결과 | 고친 모습 |
| --- | --- | --- |
| `if x > 3` (콜론 없음) | `SyntaxError: expected ':'` | `if x > 3:` |
| `if x = 3:` | `SyntaxError` | `if x == 3:` |
| 블록을 들여쓰지 않음 | `IndentationError` | 4칸 들여쓰기 |
| 블록 줄마다 칸 수가 다름 | `IndentationError` | 모두 4칸 |
| `else x < 3:` | `SyntaxError` | `else:` (조건 없음) 또는 `elif x < 3:` |
| `else if` | `SyntaxError` | `elif` |
| 넓은 조건을 위에 씀 | 엉뚱한 결과 | 까다로운 조건을 위로 |
