# 4장 문제 5 정답

## 1번
```
o g 6
```

## 2번
```
cd
abfg
```
`[2:4]`는 2, 3번. `[:2]`는 `ab`, `[-2:]`는 `fg`.

## 3번
```
True
```
`level`을 뒤집어도 `level`이에요. 이런 말을 **회문(팰린드롬)**이라고 하고, 코딩테스트에 자주 나와요.

## 4번
```
Kim
```
`lower()`는 새 문자열을 만들 뿐, `name`은 그대로예요. `name = name.lower()`라고 해야 바뀌어요.

## 5번
```
n은 {n}이에요
n은 7이에요
```
`f`가 없으면 중괄호도 그냥 글자예요.

## 6번
```
['a', 'b', '', 'c']
```
쉼표 사이가 비어 있으면 빈 문자열 `''` 조각이 생겨요. (괄호를 비운 `split()`은 띄어쓰기가 여러 개여도 빈 조각을 만들지 않아요.)

## 7번
```
a-b-c
```
`join`은 문자열의 글자 하나하나를 조각으로 보고 사이에 `-`를 넣어요.
