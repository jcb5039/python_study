# 10장 문제 6 정답

## 1번
```
{'a': 10, 'b': 2, 'c': 3}
3
```
없는 키 `'c'`는 추가, 있는 키 `'a'`는 값이 바뀌어요.

## 2번
```
5
```
`'y'`는 없어서 0, `'x'`는 5.

## 3번
```
True False
```
`in`은 **키**에서만 찾아요. 3은 값이에요.

## 4번
```
3 3
```
1은 3번 나왔고, 서로 다른 키는 1, 2, 3 세 개예요.

## 5번
```
2 [2, 4]
```

## 6번
```
[2, 3] [1]
```
교집합은 둘 다 있는 2, 3. 차집합 `a - b`는 a에만 있는 1.

## 7번
```
<class 'dict'>
```
`{}`는 빈 **딕셔너리**예요. 빈 집합은 `set()`으로 만들어요.

## 8번
```
3
```
`for k in d`는 키를 하나씩 줘요. `d[k]`로 값을 꺼내 더했어요.
