# 11장 문제 5 정답

## 1번
```
[0, 10, 20, 30]
```

## 2번
```
[12, 20]
```

## 3번
```
1 a
2 b
3 c
```

## 4번
```
[(1, 'a'), (2, 'b')]
```
길이가 다르면 짧은 쪽에 맞춰서 멈춰요.

## 5번
```
5 3 2
```

## 6번
```
[[0, 9], [0, 9]]
```
`[[0] * 2] * 2`는 같은 줄을 두 번 가리켜서, 한 줄을 바꾸면 두 줄 다 바뀌어요.

## 7번
```
['ccc', 'bb', 'a']
```

## 8번
```
[1, -2, 3, -4]
```
절댓값 1, 2, 3, 4 순서로 정렬됐어요. 값 자체는 바뀌지 않아요.
