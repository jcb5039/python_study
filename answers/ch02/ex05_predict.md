# 2장 문제 5 정답

## 1번
```
30
```
x는 10 → 15 → 30으로 바뀌어요. 오른쪽을 먼저 계산하고 왼쪽에 넣어요.

## 2번
```
73
10
```
글자끼리 `+`는 이어 붙이기, 정수로 바꾼 다음 `+`는 더하기예요.

## 3번
```
90
```
새 값을 넣으면 예전 값(80)은 사라져요.

## 4번
```
7
7.0
```
`int(7.8)`은 반올림이 아니라 **버림**이라서 7이에요.

## 5번
```
2 2
```
`a = b`에서 a가 2가 되면서 원래 값 1이 사라졌어요. 그래서 `b = a`를 해도 2가 들어가요.
값을 바꾸려면 `a, b = b, a`를 써야 해요.

## 6번
```
name
코딩
```
따옴표가 있으면 글자 `name` 그대로, 없으면 변수 `name`에 담긴 값이에요.

## 7번
```
NameError: name 'level' is not defined
```
파이썬은 위에서 아래로 실행해요. 1번째 줄을 실행할 때는 아직 `level`이 만들어지지 않았어요.
