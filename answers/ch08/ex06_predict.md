# 8장 문제 6 정답

## 1번
```
20 40 [20, 30]
```

## 2번
```
[3, 1, 2] [1, 2, 3]
```
`sorted()`는 새 리스트를 만들고 원래 리스트는 그대로 둬요.

## 3번
```
[1, 2, 3]
```
`sort()`는 원래 리스트를 직접 정렬해요.

## 4번
```
None
```
`sort()`는 아무것도 돌려주지 않아요(`None`). 그걸 `a`에 넣어서 리스트가 사라졌어요.

## 5번
```
[10, 30] 2
```
홀수인 1, 3일 때만 10을 곱해서 추가했어요.

## 6번
```
4
```
`[4, 5]`가 통째로 한 칸에 들어가서 `[1, 2, 3, [4, 5]]`가 됐어요. 이렇게 리스트 안에 리스트를 넣는 건 11장(2차원 리스트)에서 배워요.

## 7번
```
[3, 5, 1] 1
```
`remove`는 **처음 나오는 하나만** 지워요.
