# 파이썬 입문: 처음부터 코딩테스트까지

프로그래밍을 한 번도 해 본 적 없는 사람을 위한 파이썬 강의서예요.
12장으로 되어 있고, 하루에 한 장씩 하면 약 2주 걸려요.
마지막 장까지 마치면 쉬운 코딩테스트 문제를 혼자 읽고 풀 수 있는 것이 목표예요.

---

## 1. 처음 시작하는 법

1. VS Code에서 **파일 → 폴더 열기**를 누르고 `src` 안의 `python-study` 폴더를 열어요.
2. 화면 위 메뉴에서 **터미널 → 새 터미널**을 눌러요. 아래쪽에 글자를 칠 수 있는 창이 열려요.
3. [1장 강의](lessons/ch01_hello.md)를 열고 처음부터 따라 해요.

> 터미널이 뭔지 몰라도 괜찮아요. 1장에서 처음부터 설명해요.

---

## 2. 폴더 구성

| 폴더/파일 | 들어 있는 것 | 언제 보나 |
| --- | --- | --- |
| `lessons/` | 강의서 (장마다 파일 하나) | 맨 처음, 개념 공부할 때 |
| `exercises/` | 직접 푸는 문제 (빈칸이 있어요) | 강의를 다 읽은 뒤 |
| `answers/` | 정답과 해설 | **문제를 다 풀고 나서** 확인용 |
| `cases/` | 채점에 쓰는 입력과 정답 출력 | 열어 보지 않아도 돼요 |
| `judge.py` | 입출력 문제 채점기 | 채점할 때 실행만 해요 |

---

## 3. 하루 공부 순서

1. **강의 읽기**: `lessons/`에서 그날 장을 읽어요. 예시 코드는 **복사하지 말고 직접 쳐서** 실행해 봐요.
2. **문제 풀기**: `exercises/` 안의 같은 장 폴더에 있는 문제를 순서대로 풀어요.
3. **채점하기**: 아래 "4. 채점하는 법"대로 실행해서 ✅가 나오는지 봐요.
4. **정답 확인**: 다 풀었으면 `answers/`에서 해설을 읽어요. 맞혔어도 다른 풀이가 있는지 봐요.
5. **체크리스트**: 강의 맨 아래 체크리스트를 보고 스스로 설명할 수 있는지 확인해요.

막히면 30분은 혼자 고민해 보고, 그래도 안 되면 강의를 다시 보거나 질문하세요.

---

## 4. 채점하는 법

터미널이 `python-study` 폴더에 있는지 먼저 확인해요. 아니면 이렇게 이동해요.

```bash
cd ~/src/python-study
```

문제는 두 종류가 있어요. 문제 파일 맨 위에 어떤 방법으로 채점하는지 적혀 있어요.

### (1) 그냥 실행하면 채점되는 문제

문제 파일 아래쪽에 채점 코드가 들어 있어요.

```bash
python3 exercises/ch02/ex01_boxes.py
```

```
✅ city
❌ year  결과: None  기대: 2026
```

### (2) judge.py로 채점하는 문제 (입력을 받는 문제)

코딩테스트처럼 입력을 받아서 출력하는 문제예요. `judge.py`가 여러 입력을 넣어 보고 출력을 비교해요.

```bash
python3 judge.py exercises/ch05/ex02_sum.py
```

```
✅ 1번
✅ 2번
------------------------------
🎉 2/2 전부 통과!
```

### 결과 예측 문제 (`.md` 파일)

`exNN_predict.md`는 코드를 실행하지 않고 **결과를 머릿속으로 예측**하는 문제예요.
답을 파일에 적고, 그다음 직접 실행해서 맞았는지 확인해요.

## 6. 파일 이름 규칙 (내 파일을 만들 때)

- 소문자와 밑줄(`_`)만 써요: `my_test.py` ✅ / `My Test.py` ❌ / `my-test.py` ❌
- 숫자로 시작하지 않아요: `ex01_hello.py` ✅ / `01_hello.py` ⚠️
- 파이썬 기본 기능 이름은 피해요: `random.py`, `math.py` ❌ (진짜 기능 대신 내 파일을 불러와서 이상한 에러가 나요)
